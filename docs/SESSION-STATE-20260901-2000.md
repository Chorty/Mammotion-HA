## 7. 🚨 The headline finding: the intended run should NOT be dispatched as designed

**`half_diff ≈ |steady − onset| / k` models ONLY the onset interval and omits the
residual scatter.** Removing the onset interval entirely from the banked +180 run
still leaves `half_diff = 1.625 °/s` — over the 1.5 bound. **So it does not tend
to zero as k grows**, and §6.2's "passes by 8.1%" is the onset-only figure.

Bootstrapping the real ex-onset scatter (mean −12.14, sd 1.383 °/s):

| step length | k | P(2a pass) |
| --- | --- | --- |
| 15 s (the beta96 config) | 8 | **58.5%** |
| 14 intervals | 7 | 47.7% |
| 20 s | 10 | 76% |

🔑 **The predeclared run is a ~59/41 coin flip on residual noise alone** — the
same trap as the +180 repeat, re-weighted. A FAIL would be recorded as "the plant
is not steady" when it is the statistic's own noise floor; a PASS is equally
uninformative. ⚠️ **Even a 20 s step only reaches 76%**, so "make the step longer"
is not a fix, it is a slightly better coin.

**The honest conclusion: 2a needs a different statistic, not a longer window.**
That is offline work and needs no mower.
